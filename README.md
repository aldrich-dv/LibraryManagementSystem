# 📚 Library Management System

A C# console-based Library Management System developed as part of a programming assignment. The system allows users to manage books, members, and borrowing activities through a simple menu-driven interface.

## 🎯 Project Overview

The purpose of this project was to apply fundamental programming concepts in C# by developing a functional library management application.

The project demonstrates the use of:

* Object-Oriented Programming (OOP)
* Classes and objects
* Lists and collections
* Loops and conditional statements
* Methods and functions
* User input and validation
* Exception handling
* Basic data management

## ⚙️ Features

* 📖 Add and manage books
* 👤 Manage library members
* 🔄 Borrow and return books
* 🔍 Search for library information
* 📋 Display available books
* ⚠️ Input validation and error handling
* 🖥️ Menu-driven console interface

## 🛠️ Technologies Used

* **C#**
* **.NET**
* **Visual Studio**

## 📂 Project Structure

The project contains the main C# source files responsible for handling the library's functionality, including books, members, borrowing operations, and the main application logic.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in **Visual Studio**.
3. Build the solution.
4. Run the application.
5. Follow the instructions displayed in the console.
